# Film animatic

Final timing with blocking-level visuals for the About film. Run `npm ci` once for the fonts, then `node film/animatic/serve.mjs` from the repo root and open http://localhost:4329/film/animatic/ in Chrome. The page loads `film/beats.json`, the single source of timing and text, and renders it through `engine/film.js`, a pure `frame(t)` that paints the chart on one 2D canvas and every string on a second 2D canvas composited into the frame. Controls: Space plays or pauses, the arrow keys step 1 s, `[` and `]` jump chapters, and the scrubber shows chapter ticks. `?t=42.5` opens paused at that time, `?play=1` starts playing, and `?rm=1` forces the reduced-motion version (one still per beat, 0.4 s dissolves, every caption kept). Scripts can drive the page through `window.__anim` (`seek`, `pause`, `play`, `t`). Check the captions with `node scripts/film/lint-beats.mjs`.
